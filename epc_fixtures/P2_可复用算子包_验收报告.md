## 5. 已知限制：四角-only + Geom+residual 劣于 IDW

| 问 | 判定 |
|---|---|
| 是否违反需求硬门？ | **否（in-spec）** |
| 依据 | 需求 §5 H3 Op-Geom：`p95 ≤ idw_nn 同协议（允许 =；**推荐** residual 时严格 < 若 backend=residual_gbdt）`。绿路径默认 **`idw_nn`**，H3 以 idw 同协议认证（p95≈0.00767）。residual 严格优于为**推荐软指标**，非硬 FAIL。`construct.backend` 允许 idw / residual；residual 仍可跑通（smoke EXIT0）。 |
| 残留风险 | 若生产默认改 `residual_gbdt` 且未换 prior/重训，四角-only DEMO 上 p95 可能劣于 IDW（本测 0.0263 > 0.00767）。`eval_h3.py` 对 Geom 的 `ok` 主要钉 idw 有限且 `<0.2`，residual 比较为 soft flag——建议后续把「绿 backend 的 p95 ≤ idw」写成硬断言以免口径漂移。 |
